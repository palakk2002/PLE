--- TRU BUY B2B RFQ & PURCHASE ORDER SYSTEM WORKFLOW SUMMARY ---

1. RFQ (Request for Quotation) Flow Start:
- B2B Admin apne portal se bulk items ke liye ek naya RFQ form bhar kar request bhejta hai.
- Ye request Super Admin ke "Pending RFQs" tab mein aati hai. 
- Super Admin isey review karke "Assign Vendors" karta hai aur un vendors se rates (quotations) mangwata hai.

2. Vendor Quotation & Super Admin Selection:
- Vendors (jaise Samsung ya ElectroTech) apne dashboard se apna price/quote bhejte hain.
- Super Admin unme se best quote ko "Select Quote" karta hai.
- Yahan dhyan dene wali baat ye hai ki select karne ke baad Super Admin ko ek green button "Submit for B2B Approval" click karna hota hai, taaki wo order final approval ke liye B2B Admin tak pahuch sake.

3. B2B Admin Final Decision (Approve & Issue PO):
- Jab Super Admin approve karke bhejta hai, tab B2B Admin ko 3 buttons show hote hain:
  (a) Approve & Issue PO
  (b) Request Re-Negotiation
  (c) Reject Recommendation (Iska color code bg-red-650 galat tha jise theek karke bg-red-600 kar diya gaya tha, taaki button hamesha laal dikhe).

4. "Approve & Issue PO" Ke Baad Kya Hota Hai?
- Jaise hi B2B Admin PO issue karta hai, ek actual "Purchase Order" (e.g., PO-10293) generate hota hai.
- Product ka stock catalog se automatically deduct ho jata hai.
- Super Admin aur Vendor ko "PO Generated" ka system notification chala jata hai.

5. Payment Kaise Aur Kahan Se Hoti Hai?
- B2B transactions mein payment online credit card ya UPI se turant nahi hoti.
- Isme "NET 30 Days" ke Payment Terms lagte hain. Iska matlab hai ki order receive hone ke 30 din ke andar payment karni hoti hai.
- Payment completely Offline hoti hai. Vendor apna Commercial Invoice bhejta hai aur B2B company directly us vendor (ya platform) ke bank account mein RTGS/NEFT se transfer karti hai. Platform sirf deal lock karwane ka kaam karta hai.

6. Tracking Aur Dashboards:
- Super Admin & B2B Admin: B2B Admin aur Super Admin ab is Order ki live tracking apne left sidebar ke "B2B Orders" (jo pehle static tha aur ab dynamic kar diya gaya hai) ya "Purchase Orders" tab se dekh sakte hain.
- Vendor: Jis vendor ki quote accept hui hai, usey ye order B2C wale normal "Orders" section mein nahi, balki uske apne dedicated "B2B Enquiries" wale dashboard mein dikhai dega, jahan se wo isey fulfill karega.
